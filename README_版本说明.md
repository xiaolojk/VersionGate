# 版本说明：请下载 v2.0（完整版，单插件）

作者：橘子 · https://github.com/xiaolojk/VersionGate

## 装哪个

| 版本 | 做了什么 | 推荐 |
|---|---|---|
| **v2.0.0** | 改协议号 + 数据包翻译 + 进服通报，一个 `.whl` 全搞定 | ✅ 下载这个 |
| v1.3.0 | 只改登录包协议号 | ❌ 已被 v2.0 覆盖，别再装 |

v2.0 把 v1.3 的能力原样内置，又补上了真正缺失的包翻译。**装了 v2.0 就不需要 v1.3，两者也别同时装。**

## 旧版为什么不够

v1.3 只改协议号，能让旧版客户端"连进来"，但游戏包结构对不上，会皮肤错乱、物品/实体异常。相当于只改了信封邮编，信里内容对方看不懂。

v2.0 新增了**真正的数据包字段翻译**（基于官方 bedrock-protocol），双向翻译。实测 2193→2225：231 个包中 223 个兼容，只 7~8 个需翻译。

## 安装

1. **Python ≥ 3.12**（依赖 bedrock-protocol）
2. 下载 `endstone_protocolbridge-2.0.0-py3-none-any.whl` 放入 `plugins/`，重启
3. `debug = true` 用旧版客户端进服，确认日志有改写与翻译

> 环境不满足（Python <3.12）时，协议号改写仍生效，只是包翻译不启动，不会搞崩服务器。

## 限制

- 只支持 1.26.x 相邻档位，跨大版本不支持
- 未经真实客户端端到端游玩验证，请部署后实测反馈

详见 [v2.0 发行说明](RELEASE_NOTES_v2.0.md) 和 [技术文档](protocolbridge/README.md)。
