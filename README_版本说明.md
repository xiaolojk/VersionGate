# 版本说明：请下载 v3.1.0

作者：橘子 · https://github.com/xiaolojk/VersionGate

## 装哪个

| 版本 | 做了什么 | 推荐 |
|---|---|---|
| **v3.1.0** | 放行 + 1.21.x/1.26.x 深度翻译 + 方块物品防空气 + 物品 ID 映射 + 进服通报 | 最新功能版，需要 1.21.x 兼容就用它 |
| v2.0.1 | 放行 + 1.26.x 相邻小版本翻译 + 进服通报 | 稳定版，只需 1.26.x 同代兼容可选它 |
| v2.1.0 | 1.21.x 只改协议号+浅层翻译（核心包解析会失败，已证实不可靠） | 不要用 |
| v1.3.0 | 只改协议号 | 旧版，不要再用 |

**一次只装一个版本。** 装了 v3.1.0 就不需要 v1.x 或 v2.x；也不要同时放多个 whl。

## v3.1.0 相对 v3.0.0 的新增

- **方块物品防空气**：1.26 服务端的方块物品在 1.21 客户端不再变成空气。原理是把物品描述符里老客户端当"空物品"的 `id=0` 修正为非 0 值。
- **物品 ID 映射**：可配置 `1.26 新物品 ID / 方块 block_runtime_id = 1.21 已有物品 ID`，右上角面板还能可视化增删。没配到的方块用兜底 ID（默认 1 = 石头）。
- 修复一处打包导入问题：装成 wheel 后也能正常加载。

## v3.0 的深度翻译能力（v3.1 沿用）

之前的版本对 1.21.x 只是改协议号——经官方库实测，1.21 到 1.26 之间有 40 多个包结构完全不同（如 StartGame、TextPacket），浅层字段复制会导致老客户端解析失败。v3.0 重写了翻译核心：

- **逐包深度翻译**：按字段类型递归转换，嵌套对象重建（如 `BlockPos` ↔ `NetworkBlockPosition`）、枚举/int 互转、字段改名映射。
- **独有包处理**：1.26 新增的老客户端不认识的功能包自动取消发送；老客户端独有包自动取消接收。
- **双向支持**：发包（服务器→客户端）和收包（客户端→服务器）都翻译。
- **多档覆盖**：1.21.x 常用档位全部支持。
- **互不干扰**：1.26.x 客户端仍走原有的轻量翻译，性能零开销。

实测 13 档位双向共 1123 次翻译，1122 次成功且目标版本能正确 decode。

## 配置

主配置 `plugins/protocolbridge/config.toml`（首次启动自动生成，含中文注释）：

```toml
enable_deep_translation = true   # 1.21.x 深度翻译，默认开
enable_item_remap = true         # 方块物品防空气，默认开
fallback_item_id = 1             # 兜底物品 ID，默认 1=石头
```

物品 ID 映射（可选）：

```toml
[item_id_map]
20001 = 5   # 方块 bri 20001 → 1.21 木板(id=5)
12345 = 1   # 新物品 12345 → 1.21 石头(id=1)
```

改完**重启服务器**生效。

## 安装

1. **Python ≥ 3.12**（依赖 bedrock-protocol）
2. 下载 `endstone_protocolbridge-3.1.0-py3-none-any.whl` 放入 `plugins/`，重启
3. 首次启动生成 `plugins/protocolbridge/config.toml`；日志打印「分档翻译表」和启用状态
4. `debug = true` 可看每次改写与翻译

## 限制

- 685、686、860、2169 档位官方库无对应模块，仅改协议号、不翻译
- 少数序列化完全重写的包（如复杂物品 NBT）可能无法 100% 等价，属于协议代差
- 端到端逻辑通过 95 项自动化测试，但未经过真实客户端长时间游玩验证，请部署后实测反馈
